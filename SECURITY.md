# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/nalaj/metafyl/security), not in a public issue.

In scope: anything that makes a rendered story run untrusted code (for example, an HTML or script injection from transcript content), makes the extractor read outside the transcript and project directories, or makes the skill send data over the network.

A story page is meant to contain your session's prompts, replies, diffs and commands verbatim. Secrets that passed through the session appearing in the page is expected behaviour, not a vulnerability. Review a page before sharing it.
