Install the skill

One command, through the open skills CLI. Nothing to publish or configure, and no npm dependencies at runtime. The installer needs Node.js 22.20+; the skill runs on 18.18+.

Agent
Scope 

          
        

        
The skill installs into this agent, but it only reads Claude Code transcripts (~/.claude/projects). Use it here to make stories of your Claude Code sessions.

        
Run the same command again to update. Remove it with npx skills remove session-story.

03

        

          
One page, four readers

          
Switch views to suit who's reading. Everything is inline (CSS, JS and data), so the page works straight from file:// or as an email attachment.

        

      

      

        

          
Review
for you
A timeline of turns: the prompt, a one-sentence intent, Claude's answer, and the code behind it, with time and tokens for each turn.

          
Diff
for a code reviewer
A GitHub-style file tree and diff, with every hunk tagged with the turn that produced it.

          
Story
for a stakeholder
A narrative card per turn, in plain language, with the code folded away.

          
Report
for anyone asking "so?"
Outcome, plan, commands, tests, errors and how they were fixed, decisions, git state, and where the time and tokens went.

04

        

          
How it works

          
The numbers come from the transcript, never from the model. Claude writes only the prose, and it works from a compact brief rather than the raw transcript.

        

      

      

        

          
Extract
Parses the transcript (and any subagent transcripts) into typed JSON. It records edits, commands, errors, git state, durations and token usage, and leaves anything unrecorded as null.

          
Summarize
Claude writes the title, a one-sentence intent per turn, and the plan, decisions and outcome.

          
Validate
Checks the JSON against the schema, and in strict mode that no summary is missing.

          
Render
Deterministically compiles one self-contained HTML file and indexes it in the project's session library.

        

        
The page contains your prompts, Claude's replies, diffs and commands, word for word. Read it before you share it, since a session can include secrets. Nothing is uploaded: the skill reads local files and makes no network requests.
